Public game uploads

Export a game from Pixel Vault's My Library with “Export public ZIP”, then upload that ZIP to this folder. The deployment workflow extracts each ZIP, adds its entry HTML to public-catalog.json, and publishes the files for all visitors.

Keep each ZIP below GitHub's file-size limit (the Pixel Vault exporter stops at 24 MB). Include only games and assets you created or are allowed to redistribute. A ZIP should contain the game's HTML file and its supporting assets; Pixel Vault's exporter adds a .pv-game.json entry manifest automatically.
