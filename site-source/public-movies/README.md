Public movie uploads

Upload public-domain movies, videos you created, or files you have permission to redistribute to this folder. On the next successful deployment, MP4, WebM, M4V, MOV, OGV, and OGG video files are listed in the shared Public Catalog for everyone.

The in-site importer is local-only; use “Download to publish” to save a movie and then upload it here. GitHub has file-size limits, so the UI currently prepares files up to 90 MB for this route.
